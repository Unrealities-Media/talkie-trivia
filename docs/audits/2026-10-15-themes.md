# Light and dark theme consistency

Preserved existing uncommitted work. Local changes only.

- Search results, previews, year strips and empty results now use theme surfaces
  and text colors. Cinema artwork and the projection retain their own palette.
- Active tabs use readable accent text and a selected surface; secondary button
  outlines use the same accent. Button labels can shrink and wrap.
- Hint notes and remaining guesses use readable secondary text in both themes.
- Result dividers and poster frames use theme colors.
- Archive and Profile share header sizing, gutters, content width, bottom spacing
  and the background gradient used by Play. Navigation scenes use the theme
  background while loading.

Validation: TypeScript and diff whitespace checks passed. Eight targeted suites
passed (61 tests), followed by the expanded readability suite (16 tests, including
four new checks for navigation and search contrast across both themes).

Local Chromium checked Play, Archive and Profile at 320, 390 and 1440 pixels in
both themes: no document horizontal overflow or page errors. Search, confirmation
and result captures were also inspected. Browser scripts and captures are under
`.expo/theme-review.cjs`, `.expo/theme-review.json` and `.expo/theme-*.png` (ignored).
Native device rendering, keyboard and font scaling were not exercised in this pass.
